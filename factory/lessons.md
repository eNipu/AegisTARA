# Factory lessons

What the factory learned from failed gates, reviewer findings and owner reworks. The
orchestrator writes this file; agents only read the lines with their tag. One line per
lesson: the cause, not the symptom. At most 25. `seen: 3` gets `PROMOTE`, and `/factory retro`
then proposes to turn it into a check or a rule.

- L09 [builder] A test for a new guard needs an input that only that guard refuses, and must check which error comes back. Evidence: job 162 slice 162c (260-letter path was refused without the fix); job 102 slice 102a (two script test cases still passed with their rule switched off); job 124 slice 124b (over-cap test also broke the outer list that shares the same limit). seen: 3 PROMOTE
- L11 [planner] A "Done when" item that needs clicks or screenshots cannot be met by an agent without macOS Accessibility and Screen Recording permission; plan it as an owner check from the start. Evidence: job 181 slices 181a, 181b. seen: 2
- L12 [builder] Before committing, count the changed source lines (`git diff --numstat <base>`, without tests, docs and lock files) against the slice's `max_lines`. Evidence: job 181 slices 181a, 181b (490 lines, cap 400); job 102 slice 102a (224 lines, cap 200).; job 134 slice 134a (645 lines, cap 600).; job 136 slice 136d (592 lines, cap 580); job 136 slice 136e (461 lines, cap 440); job 143 slice 143b (380 lines, cap 320) seen: 7 PROMOTE
- L14 [planner] Size a slice from everything its prompt demands, doc comments and doc tests included; a store, its ops and their op log lines do not fit one 400-line slice. Evidence: job 205 slice 205b (475 lines, cap raised to 480 by the owner).; job 182 slice 182b (730 lines, cap 600, split into 182b and 182b2); job 182 slice 182c (699 lines, cap 600, split into 182c and 182c2); job 182 slice 182d (956 lines, split in three); 182e (761 lines) 208d (633 lines); job 136 slice 136a (622 lines); job 137 slice 137a (600 lines) seen: 8 PROMOTE
- L16 [planner] When a prompt lists the facts a security document must state, take each fact from the code for every login mode and every way of running the server (image, compose file), not from one path. Evidence: job 102 slice 102a (keychain described for password login only; listen address described for the compose file only); job 102 slice 102c (personal data inventory missed report profiles and the company-login keychain entries). seen: 2
- L18 [orchestrator] Before a note tells the builder to touch a file, check the slice's `allow` list in `plan.json` and have the planner add the file first. Evidence: job 102 slice 102c (gate failed as out of scope on chapter 3). seen: 1
- L19 [builder] When the prompt says an ID differs, compare the IDs, not the names shown for them; names can repeat and can be renamed. Evidence: job 119 slice 119f (comparison reported a renamed system as a component move). seen: 1
- L20 [builder] A rule applied once per page needs a test that covers every page the prompt lists and calls each extra entry point directly; a helper that samples a few pages lets a miswired page pass. Evidence: job 119 slice 119h (5 of 9 filtered pages tested, `filter_threats` never called). seen: 1
- L21 [planner] A prompt that says "filter every table" must specify a test fixture holding one element of every kind filtered and name a check for every computed number; otherwise filter lines ship with no test that can fail. Evidence: job 121 slice 121a (review CHANGES, tests added for every system filter and the summary counts). seen: 1
- L22 [planner] When a count must equal the rows of a sheet, say "count the rows where the sheet is built", not "find the sheet by name": methodology names are data and can repeat. Evidence: job 121 slice 121b (review CHANGES). seen: 1
- L23 [builder] Thread a new parameter through the existing row builders with the smallest diff instead of rewriting them; a rewrite pushes the slice over the gate size limit. Evidence: job 121 slice 121b (gate FAIL at 350 lines, 216 after shrinking). seen: 1
- L24 [planner] Adding a required field to a public struct forces an edit at every construction site, doc examples and test fixtures included; put those files in the allow list when cutting the slice, not after the gate fails. Evidence: job 131 slice 131a (error.rs doc tests and catalog.rs fixture out of scope, gate FAIL, re-cut and round 2); job 164 slice 164d (new command rows at the top broke the expected order in aegis-client tests/palette.rs, builder NEXT: planner). seen: 2
- L25 [planner] A count rule copied from nav_counts ("Versions = baselines if >0") must name the state each rule reads; a fixed &Workspace signature made one rule impossible, and the builder documented the gap instead of the prompt being cut to fit the data available. Evidence: job 131 slice 131b (review CHANGES, NEXT: planner). seen: 1
- L26 [orchestrator] The owner's session can move master while a job is in flight; before Merge, check `git merge-base master factory/<job>` and integrate master into the branch (builder, both sides kept) and re-gate against the new master, instead of merging into a moved master. Evidence: job 131 (129c landed mid-job, merge conflict in view.rs, integration round). seen: 1
- L27 [planner] Name Fluent message ids with hyphens: Fluent cannot parse dotted ids, so a prompt that uses them forces a deviation. Evidence: job 149 slice 149a. seen: 1
- L28 [builder] Do not meet a source-line cap by compressing code onto `#[rustfmt::skip]` lines; it passes the gate and fails review. Ask the planner to raise a wrong cap instead. Evidence: job 150 slice 150a (rework compressed, reviewer flagged, planner raised the cap and the rework was reverted). seen: 1
- L29 [builder] A new reference-typed field on a goal or claim must be resolved by public ID in BOTH `Project::eq` and every `diff_arena` closure; a derived `PartialEq` on raw indices breaks the slot-layout contract and yields spurious diff lines. Evidence: job 145 slice 145b (three review rounds). seen: 1
- L30 [planner] When a job adds a link or field to an element, the spec must say what happens to it when that element, step or tree is removed or unlinked, and must require a test that removes it, undoes, and compares the project. An inverse such as `AddAsset` or `LinkDamage` cannot carry the new data: either the model refuses the removal until the data is cleared, or the client edit clears it first in the same undo step. Also list every storage format the field must reach: snapshot, op log and workspace files. Evidence: jobs 145 (goal and claim parties, plus parties missing from workspace files), 146 (pair rationale) and 133 (condition links) all lost data on undo, and second reviews caught it after merge. seen: 3
- L31 [reviewer] A PASS needs a test that fails when the feature is wrong, not one that only shows the types exist. Read the test helpers in the diff: a generator that skips ops, an arm that cannot be reached, or a test that reopens state after every edit hides the fault. Evidence: job 145 (`is_party_op` skipped party ops to hide the workspace gap), 133 (duplicate generator arm 73), 150 (picker tests reopened the picker and hid stale state). seen: 3
- L32 [planner] Before a prompt says existing code already handles a case, read that function's entry checks: `matches_tree` refused any node without a value, so excluded steps emptied path analysis and the slice needed a file outside its list. Evidence: job 134 slice 134b (gate FAIL, builder NEXT: planner, paths.rs added). seen: 1
- L33 [builder] Text read from a file the user opens (manifest keys, versions, names) must be cut to a fixed length before it goes into an error message; an old or hostile folder can hold any length. Evidence: job 164 slice 164c (methodology key and version shown uncut in the refusal message). seen: 1
- L34 [planner] Set `new_deps` true for any slice that adds a dependency to a crate, even a workspace crate or one already in the lock file: `Cargo.lock` changes either way and the gate refuses it. Evidence: job 208 slice 208d (aegis-license added to aegis-workbench). seen: 1
- L35 [builder] When reference leaves join generated fixtures, update independent analysis oracles to fold referenced inputs; own/shared-only leaf accessors cannot provide fragment-root values. Keep expectations independent of production evaluation and preserve saved failure seeds. Evidence: job 142 slice 142e (sensitivity properties failed on fragment leaves). seen: 1
- L36 [builder] Defer extra DAG link insertions until after owned-node insertions when building an AttackTree arena in topological order; otherwise a linked child placed ahead of its extra parent breaks sibling-based `insert_child` placement. Evidence: job 142 slice 142i. seen: 1
- L37 [builder] Putting an unrated leaf in the same `OR` gate as excluded or merged-overlay branches forces evaluation to `Unrated` and masks failures in copied exclusions or overlays; keep unrated cases in a separate tree. Evidence: job 142 slice 142k. seen: 1
