2. `SystemSet`: `#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash)] pub struct SystemSet(u64);` Bit `i` stands for the system with rank `i` in ID order. Methods, all `const fn` and O(1): `EMPTY`, `is_empty()`, `len() -> usize`, `union(self, other) -> SystemSet`, `intersects(self, other) -> bool`, and
   `shows_in(self, view: SystemSet) -> bool` = `self.is_empty() || self.intersects(view)` ("An element with nothing to derive from shows in every view").
3. `SystemUse`: holds `systems: Vec<ElementId>` (rank order) and one `Vec<SystemSet>` per kind, indexed by the arena index (`idx.index()`), grown with `resize` as needed. Public methods:
   - `systems(&self) -> &[ElementId]`
   - `set_of(&self, ids: impl IntoIterator<Item = ElementId>) -> SystemSet` (an ID that is not a live system is ignored; binary search)
   - `ids(&self, set: SystemSet) -> impl Iterator<Item = ElementId> + '_` (rank order)
   - one getter per kind returning `SystemSet` (`EMPTY` for an unknown index): `component(ComponentIdx)`, `interface(InterfaceIdx)`, `data_flow(DataFlowIdx)`, `trust_boundary(TrustBoundaryIdx)`, `asset(AssetIdx)`, `threat(ThreatIdx)`, `tree(TreeIdx)`, `damage(DamageIdx)`, `control(ControlIdx)`, `goal(GoalIdx)`, `claim(ClaimIdx)`.
4. `impl Project` in `system.rs`:
   - `pub fn component_system(&self, idx: ComponentIdx) -> Option<ElementId>`: the system of the component's top-level ancestor. Walk `parent()` at most `MAX_COMPONENT_DEPTH + 1` steps. Time O(depth).
   - `pub fn system_use(&self) -> SystemUse`. When the project has no systems, return at once with every list empty. Rules:
     - component: the set holding `component_system`, or empty.
     - interface: its component's set.
     - data flow: union of the sets of `from` and `to`.
     - trust boundary: union of its members' sets.
     - asset: its component's set, or empty when unbound.
     - threat: its asset's set.
     - tree: union over the threats whose `attack_tree` is this tree.
     - damage scenario: union over the threats that link it.
     - goal, claim: union over the threats whose `goal` or `claim` it is.
     - control: union of the sets of its `control_targets` (a component or an interface), of every tree in which a step is mitigated by it (`step_mitigations`), and of every goal whose `controls()` contain it. Compute trees and goals before controls.
   - Document the cost: time O(components x depth + interfaces + flows + boundary members + assets + threats + damage links + tree nodes + mitigations + goal links), space one word per element.
