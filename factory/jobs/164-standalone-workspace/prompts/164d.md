## Goal
The GPUI workbench (`crates/aegis-workbench`) shows only an in-memory sample and loses every change on close. Slices 164a to 164c added `aegis_client::folder::WorkspaceFolder` (open, create, save with a journal) and `aegis_workbench::convert` (old project folders). This slice wires them into the workbench: three commands (Open Folder… ⌘O, Save ⌘S, Save As… ⌘⇧S) in the one command table, a File menu, the folder name as the project name, a status bar that says whether there are unsaved changes, saving before the window closes, and `aegis-workbench <folder>` from the shell.
