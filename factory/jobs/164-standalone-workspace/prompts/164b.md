# Build prompt: 164b Save journal so a killed save leaves whole files, with recovery on open

## Goal
Slice 164a added `crates/aegis-client/src/folder.rs`: `WorkspaceFolder::{open, create, convert_beside, save}`, where `save` writes each changed file as `<path>.aegis-new` and renames it at once. A crash in the middle leaves some files new and some old, and the strict reader may then refuse the folder (a reference to an element in no file). This slice makes a save all-or-nothing with a small roll-forward journal, recovers an interrupted save on the next open, refuses a hostile journal, and records the design in an ADR.
