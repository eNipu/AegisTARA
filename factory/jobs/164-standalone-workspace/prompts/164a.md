# Build prompt: 164a Open, create and save a workspace folder on disk

You are implementing one small change in the AegisTARA repository (Rust workspace).
Work only inside `factory/worktrees/164-standalone-workspace/`, on branch `factory/164-standalone-workspace`.

## Goal
`aegis-model` can already turn a `Project` into a list of `(path, bytes)` workspace files and back, without touching the disk (job 162). This slice adds the disk side in `aegis-client`: a new module `folder` that opens a workspace folder into a `Project`, creates a new folder from a project, and saves a project by writing only the files whose bytes changed. It reads untrusted folders, so every read is capped and symbolic links are refused. The crash-safe journal comes in the next slice (164b); here each file is written atomically on its own.

6. `fn take_lock(root: &Path) -> Result<File, FolderError>`: open or create `root/.aegis.lock` (read, write, create, `truncate(false)`), then `try_lock()`; `Err(TryLockError::WouldBlock)` → `Locked`, other errors → `Io`.
7. `fn collect(root: &Path) -> Result<Vec<(String, PathBuf, u64)>, FolderError>`, the read set (path, full path, length), sorted by path:
   - Root level: regular files whose name ends in `.json`, except `manifest.json` (the old folder store's).
   - Every regular file under `shared/` and `systems/`, recursively, at most `MAX_DEPTH` directory levels below the root (deeper → `TooDeep`).
   - Skip every name that starts with `.` and every name that ends with `.aegis-new`. Ignore everything else at the root (`.git`, `README.md`, `ops.jsonl`, `snapshots/`...).
   - Use `symlink_metadata`; a symbolic link anywhere in the walked set (including `shared` or `systems` themselves) → `Symlink`.
   - Use the file length from the metadata: over `MAX_WORKSPACE_FILE_BYTES` → `TooLarge`; more than `MAX_WORKSPACE_FILES` entries → `TooManyFiles`; sum over `MAX_PROJECT_FILE_BYTES` → `TooBig`. All three are checked before any file is read.
   - Names that are not valid UTF-8 are passed on lossily, so the model refuses them by path.
8. `fn read_capped(path: &Path, rel: &str, cap: u64) -> Result<Vec<u8>, FolderError>`: `File::open(..).take(cap + 1).read_to_end`, more than `cap` → `TooLarge` (the file may grow after `collect`).
9. `pub fn open(root: &Path, methodology: Arc<Methodology>) -> Result<(Self, Project), FolderError>`: take the lock; `root/aegis.json` must be a file, else `NotAWorkspace`; `collect`; read each file; `Project::from_workspace_files`; store the bytes read in `written`. Nothing partly built is returned on error.
10. `pub fn create(root: &Path, project: &Project) -> Result<Self, FolderError>`: if `root` exists it must hold only names starting with `.`, else `NotEmpty`; `create_dir_all`; lock; empty `written`; `save(project)`.

Doc: other files in the folder are not touched; the caller must have released any other lock on `.aegis.lock` first (used by slice 164c for old project folders).
12. `pub fn save(&mut self, project: &Project) -> Result<SaveReport, FolderError>`:
    - `files = project.to_workspace_files()?`.
    - `changed` = files whose bytes differ from `written[path]` (or are not in it); `removed` = keys of `written` that are not in `files`.
    - Nothing changed and nothing removed → return the empty report without touching the disk.
    - For each changed file: `create_dir_all(parent)`; write `<path>.aegis-new` (create, truncate), `write_all`, `sync_all`; `rename` it over `<path>`. For each removed path: `remove_file`, ignoring `NotFound`. Remove only paths from `written`, never anything else.
    - On Unix only (`#[cfg(unix)]`), `File::open(dir)?.sync_all()` every directory that got a rename or removal.
    - Update `written` only after every step succeeded; return the report.
13. Accessors: `pub fn root(&self) -> &Path`; `pub fn name(&self) -> String` (the last path component, lossy, or the whole root if it has none); `pub fn is_workspace(root: &Path) -> bool` (free function: `root/aegis.json` is a file).
