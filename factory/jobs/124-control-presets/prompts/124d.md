# Build prompt: 124d A control remembers its preset: Op::SetControlKind

You are implementing one small change in the AegisTARA repository (Rust workspace).
Work only inside `factory/worktrees/124-control-presets/`, on branch `factory/124-control-presets`.

## Goal
A security control can record which pack preset ("control kind") it was made from. The new `Op::SetControlKind` sets or clears it, with an exact inverse, and the kind is saved in the op log and the snapshot. The kind changes no risk number; it lets the app say "this is Secure boot from the pack" and later tell when its rules were changed. The op log and the snapshot are untrusted input, so the new field is decoded with the same checks as the others.

## Facts from earlier slices
- `aegis_model::ControlKind` is a 1-byte index of a preset in a `Methodology` (`crates/aegis-model/src/methodology/mod.rs`, search `ControlKind`). `Methodology` has `control_kinds()`, `control_kind(key: &str) -> Option<ControlKind>`, `control_kind_key(kind) -> Option<&str>`.
- The built-in ISO pack (`Methodology::iso21434_r155()`) declares 12 presets; the first is `secure-boot`, another is `debug-port-locked`. The second test methodology (`common::second()` in `crates/aegis-model/tests/common/mod.rs`) declares none.
