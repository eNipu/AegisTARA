## The format (copy exactly)
In the methodology object, after `attack_types` and before `translations`; omitted when the list is empty:
```json
    "control_kinds": [
      {
        "key": "secure-boot",
        "label": "Secure boot",
        "rules": {
          "bootloader-exploit": "low",
          "firmware-modification": "low"
        }
      },
      {
        "key": "debug-port-locked",
        "label": "Debug port locked",
        "interface_kinds": [
          "debug"
        ],
        "rules": {
          "debug-access": "low",
          "flash-read-out": "low"
        }
      }
    ],
```
- Field order in one entry: `key`, `label`, `interface_kinds`, `rules`.
- `interface_kinds` is omitted when empty. On reading, a missing field gives an empty list.
- `rules` is required. It is written in key order (the `BTreeMap` order).
- In a translation object, `"control_kinds": {"secure-boot": "セキュアブート"}` comes after `attack_types`; omitted when empty.
