## Goal
A methodology definition can carry setting presets ("control kinds"): a key, a label, the interface kinds the preset is for (none means it is for components) and its default rules (attack type to feasibility ceiling). `Methodology::new` checks them and `Methodology` hands them out as typed values. This is the data the later slices read from pack files and copy into security controls, so a consultant picks "Secure boot" instead of typing its rules in every project.

Pack files are not read or written in this slice (124b does that).
