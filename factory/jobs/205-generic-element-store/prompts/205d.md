## Goal
Slices 205a to 205c added the generic element store on `Project` (misuse cases, `MU`) with
add, rename, remove and set-attribute ops. This slice adds links: a misuse case links any
number of threat scenarios (N:M, requirement FND-13), through two ops, `LinkElement` and
`UnlinkElement`, with exact inverses and op log lines. Which targets a kind may link is read
from the kernel kind table (`KindDef::targets`), so later kinds only add a row. A threat
scenario that an element links cannot be removed until the link is gone, so no op ever leaves
a dangling link.
