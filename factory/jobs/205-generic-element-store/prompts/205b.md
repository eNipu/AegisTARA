## Do
1. **`element.rs`: the element and the store.**
   ```rust
   /// An element of a generic kind: its kind, name and provenance (attributes and links come in 205c, 205d).
   #[derive(Clone, Debug, PartialEq, Eq)]
   pub struct Element { kind: ElementKind, name: Arc<str>, provenance: Provenance }
   impl Element { pub fn kind(&self) -> ElementKind; pub fn name(&self) -> &str; pub fn provenance(&self) -> &Provenance }

   #[derive(Clone, Debug, Default)]
   pub(crate) struct ElementStore {
       kinds: BTreeMap<ElementKind, KindSlot>,
       kind_of: BTreeMap<ElementId, ElementKind>,   // every live element
   }
   #[derive(Clone, Debug, Default)]
   struct KindSlot {
       live: BTreeMap<ElementId, (u32, Element)>,   // visual number, element
       next_visual: u32,
       removed_visuals: BTreeMap<ElementId, u32>,   // so an undone removal gets its number back
   }
   ```
   `pub(crate)` methods, each O(log n): `get(&self, ElementId) -> Option<&Element>`, `get_mut`, `visual_num(ElementId) -> Option<u32>`, `count(ElementKind) -> usize`, `iter(ElementKind) -> impl Iterator<Item = (ElementId, &Element)>` (ID order), `insert(ElementId, Element)` (number = the removed number of this ID if any, else `next_visual`; then `next_visual = max(next_visual, number + 1)`; numbers are never reused), `remove(ElementId) -> Option<Element>` (remembers the number in `removed_visuals`), and `same_live(&self, other: &Self) -> bool` comparing, for every kind in `ElementKind::ALL`, the live `(id, element)` sequences only (not numbers, not `removed_visuals`; typed kinds also ignore visual IDs in `==`).
