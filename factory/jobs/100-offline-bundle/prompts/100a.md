# Build prompt: 100a Sign and verify an offline bundle folder in aegis-license

You are implementing one small change in the AegisTARA repository (Rust workspace).
Work only inside `factory/worktrees/100-offline-bundle/`, on branch `factory/100-offline-bundle`.

## Goal
After this slice, the `aegis-license` crate can write, sign and verify an offline bundle folder for air-gapped customer sites: a `SHA256SUMS` file (GNU `sha256sum` text format) listing every file in the folder, and `SHA256SUMS.sig`, a raw 64-byte Ed25519 signature over the exact bytes of `SHA256SUMS`, made with the **update** key. A raw signature over plain text is what a customer can check with OpenSSL 3, without running our binary. Later slices add the CLI commands, the build script and the docs.

Bundle folder layout (fixed by this job):
```
SHA256SUMS          "<64 lowercase hex>  <path>\n" per file, sorted by path bytes
SHA256SUMS.sig      raw 64-byte Ed25519 signature over SHA256SUMS
update.aegis        the release's signed update manifest (AEGIS-UPDATE-1)
installers/<file>   desktop installers; each file's SHA-256 must be an artifact sha256 in update.aegis
images.tar.gz       optional, any other top-level file is allowed if listed
```

2. In `bundle.rs` define these public items:
   - `pub const SUMS_FILE: &str = "SHA256SUMS";` `pub const SIG_FILE: &str = "SHA256SUMS.sig";` `pub const BUNDLE_MANIFEST: &str = "update.aegis";` `pub const INSTALLERS_DIR: &str = "installers";`

   - `#[derive(Clone, Debug, PartialEq, Eq)] pub struct SumsEntry { pub path: String, pub sha256: String }`
   - `#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)] pub enum BundleError` with variants: `TooLarge`, `Malformed(&'static str)`, `BadSignature`, `Missing(String)`, `Unlisted(String)`, `NotAFile(String)`, `Mismatch(String)`, `NotInManifest(String)`, `Manifest(ManifestError)` (with `#[from]`), `Io(String)`, `Signing`. String payloads are bundle-relative paths; for a name read from disk that fails validation, store `format!("{:?}", name)` cut to `MAX_PATH_BYTES` chars, never raw bytes. Error messages never echo file contents.
   - `#[derive(Clone, Debug, PartialEq, Eq)] pub struct BundleReport { pub key_id: String, pub release: Version, pub files: usize }`
3. Path rule, private `fn valid_path(path: &str) -> bool`: length 1..=`MAX_PATH_BYTES`; split on `/` into 1..=`MAX_DEPTH` components; each component starts with an ASCII letter or digit and has only ASCII letters, digits, `.`, `_`, `-`. So no `..`, no leading `/`, no hidden files, no spaces or backslashes.
4. `pub fn parse_sums(text: &str) -> Result<Vec<SumsEntry>, BundleError>`: `TooLarge` if `text.len() > MAX_SUMS_BYTES`; `Malformed(..)` unless: non-empty, ends with `\n`, no `\r`; each line is exactly 64 chars of `0-9a-f`, then two spaces, then a `valid_path`; paths strictly increasing by byte order (so no duplicates); neither `SUMS_FILE` nor `SIG_FILE` listed; 1..=`MAX_BUNDLE_FILES` lines. Time O(n).
5. `pub fn render_sums(entries: &[SumsEntry]) -> String`: `format!("{sha256}  {path}\n")` per entry, in the given order.
6. `pub fn verify_sums_signature(sums: &[u8], signature: &[u8], keys: &TrustedKeys) -> Result<String, BundleError>`: `BadSignature` unless `signature.len() == 64` and one trusted key verifies `sums` with `ring::signature::ED25519`; returns that key's ID. Add `pub(crate) fn iter(&self) -> impl Iterator<Item = (&str, &[u8; 32])>` to `TrustedKeys` in `keys.rs` for this (at most `MAX_TRUSTED_KEYS` = 8 tries).
7. Private `fn list_files(dir: &Path) -> Result<Vec<String>, BundleError>`: walks `dir` with `std::fs::read_dir` down to `MAX_DEPTH`, using `symlink_metadata` (never follows links). A symlink or anything that is not a regular file or directory gives `NotAFile(path)`; a directory at depth 2 gives `NotAFile`; a name that is not valid UTF-8 or fails `valid_path` gives `Malformed("a file name")`; more than `MAX_BUNDLE_FILES + 2` entries gives `TooLarge`. Skips `SUMS_FILE` and `SIG_FILE` at the top level only. Returns paths joined with `/`, sorted by bytes. I/O errors become `Io(path)` (the path, not the OS message text if it could echo content; the OS error kind is fine).
8. Private `fn sha256_file(path: &Path) -> Result<String, BundleError>`: streams the file through `ring::digest::Context` in 64 KiB reads, returns 64 lowercase hex (write your own small `hex`; the one in `manifest.rs` is private and that file is outside this slice).
9. `pub fn sums_for_dir(dir: &Path) -> Result<String, BundleError>`: `list_files`, hash each, `render_sums`, then `parse_sums` the result as a self-check before returning it.
10. `pub fn verify_bundle_dir(dir: &Path, keys: &TrustedKeys) -> Result<BundleReport, BundleError>`, in this order:
    a. `SUMS_FILE` and `SIG_FILE` must be regular files (`symlink_metadata`), else `Missing`/`NotAFile`; `SUMS_FILE` longer than `MAX_SUMS_BYTES` gives `TooLarge` (check the length before reading); `SIG_FILE` read only if its length is 64, else `BadSignature`.
    b. `verify_sums_signature` on the raw bytes, then `parse_sums` (the bytes must be UTF-8, else `Malformed`).
    c. `list_files(dir)` must equal the listed paths: a listed path not on disk gives `Missing(path)`, a path on disk not listed gives `Unlisted(path)`.
    d. Each file's `sha256_file` must equal its line, else `Mismatch(path)`.
    e. `BUNDLE_MANIFEST` must be listed (else `Missing("update.aegis")`); read it (it is at most `MAX_MANIFEST_BYTES` because its hash already matched, but still refuse a longer file with `TooLarge`) and `Manifest::verify(&text, keys)?`.
    f. At least one path starts with `installers/` (else `Malformed("no installer")`), and every such file's sha256 equals some `artifact.sha256` in the manifest, else `NotInManifest(path)`.
    g. Return `BundleReport { key_id, release: manifest.release(), files: entries.len() }`.
11. `pub fn public_key_pem(keys: &TrustedKeys, key_id: &str) -> Option<String>`: SPKI DER is the 12 bytes `30 2a 30 05 06 03 2b 65 70 03 21 00` followed by the 32-byte key; return `"-----BEGIN PUBLIC KEY-----\n{base64 STANDARD with padding}\n-----END PUBLIC KEY-----\n"` (use `base64::engine::general_purpose::STANDARD`).
12. In `issuer.rs` add `pub fn sign_bundle_sums(&self, sums: &str) -> Result<[u8; 64], BundleError>`: `parse_sums(sums)?` first, then `self.pair.sign(sums.as_bytes())`, copied into `[u8; 64]` (`Signing` if the length is wrong).
13. In `lib.rs`: `pub mod bundle;` (public module, so callers write `aegis_license::bundle::verify_bundle_dir`), and re-export `BundleError` at the crate root. Add one line to the crate doc list describing the bundle.

A helper builds a valid bundle: a generated update key (`Issuer::generate`, `TrustedKeys::single("upd", public)`), one installer file `installers/aegis-0.4.0-linux-x86_64.tar.gz` with some bytes, `images.tar.gz` with some bytes, an `update.aegis` from `issuer.sign_manifest` whose single artifact has that installer's sha256 and byte length (`https://downloads.example.com/...` URL), then `sums_for_dir` written to `SHA256SUMS` and `sign_bundle_sums` written to `SHA256SUMS.sig`.
