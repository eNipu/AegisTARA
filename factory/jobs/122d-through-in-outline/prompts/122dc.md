## Goal
A step of a library item may name an attack type by its pack key. Inserting the item sets that
attack type on the copied step as a normal value the user can change, and says so: the preview
shows it and the origin note in the tree's description counts the steps it was filled in on.
Library trees then work with security settings (which match on attack type) without re-typing.
