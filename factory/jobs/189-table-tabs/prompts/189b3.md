     - Document `# Errors` and time complexity (`O(input.len())`).
     - First reject `input.len() > MAX_PASTE_BYTES` with `Err(GridError::PasteTooLarge)`.

     - Parse strictly per RFC-4180 with `\t` field separator and `\r\n` / `\n` row endings, tracking 1-based `line` across ALL `\r\n` and `\n` (including newlines embedded inside quoted multiline fields!):
       - At the start of a field, `"` opens a quoted field (record `open_line = line`):
         - Inside quotes: `""` decodes to a literal `"`; any `\r\n` or `\n` is appended to the field and increments `line`; a closing `"` MUST be followed by `\t`, `\r\n`, `\n`, or EOF — any other character (e.g. `"foo"bar`) returns `Err(GridError::MalformedQuote { line })`!
         - Reaching EOF while still inside quotes returns `Err(GridError::MalformedQuote { line: open_line })`.
       - Inside an unquoted field: any `"` (e.g. `foo"bar`) returns `Err(GridError::MalformedQuote { line })`!
     - Enforce limits WHILE parsing (before pushing beyond the cap, so adversarial input cannot allocate unbounded vectors):
       - `row.len() > MAX_PASTE_COLS` -> `Err(GridError::TooManyCols)`
       - `rows.len() > MAX_PASTE_ROWS` -> `Err(GridError::TooManyRows)`
