You are implementing one small change in the AegisTARA repository (Rust workspace).

## Goal
After this slice the GPUI start screen has its second column, "Company server": the server address and connection type, the login form the server asks for (company login through the browser, user name and password with "keep me logged in", or a development user name), a status line for the five connection states (Choose server, Connecting, Online, Offline, Login required), the server's project list with Open, New project, Refresh, Sign out and Change server. Opening or creating a project shows its downloaded version read-only in the workbench, with the server name and the lease holder in the reason; Back to Start closes it and shows the list again. All logic is in `aegis_client::signin::SignIn` (slice 208b); this slice only renders it and forwards clicks.
