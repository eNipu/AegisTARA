## Facts you need
- A system is an element of kind `ElementKind::System`; `project.elements(ElementKind::System)` yields `(ElementId, &Element)` in ID order; `e.name()` is its name.
- `project.system_use()` gives a `SystemUse`. An element shows in a view when `usage.<kind>(idx).shows_in(view_set)`; an element with no system shows in every view.
- The server refuses an audit detail that is not printable ASCII (`is_ascii_graphic` or space) or is longer than 256 bytes.
- Every page row type (`ComponentRow`, `InterfaceRow`, `DataFlowRow`, `TrustBoundaryRow`, `AssetRow`, `DamageRow`, `RiskRow`, `TreeRow`, `ControlRow`, `GoalRow`, `ClaimRow`) has an `id` field; `Project` has `component_idx(&id)`, `interface_idx`, `data_flow_idx`, `trust_boundary_idx`, `asset_idx`, `damage_scenario_idx`, `threat_scenario_idx`, `attack_tree_idx`, `security_control_idx`, `cybersecurity_goal_idx`, `cybersecurity_claim_idx`. `AppliedSettingRow.target` is an `aegis_model::ItemRef` (`Component(id)` or `Interface(id)`). `ProblemRow.target` is `Option<Selection>`.
